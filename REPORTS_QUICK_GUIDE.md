# Reports Feature - Quick Start Guide

## 🎯 Accessing Reports

1. Log in as an admin user
2. Click **"Reports"** in the sidebar, or
3. Click **"Generate Reports"** button on dashboard

---

## 📊 Generating a Report

### Step 1: Select Date Range
Choose one of:
- **All Time** - All requests ever submitted
- **Monthly** - Select month and year
- **Quarterly** - Select quarter (Q1-Q4) and year
- **Custom Range** - Select start and end dates

### Step 2: Apply Filters (Optional)
- **Unit**: Hold Ctrl/Cmd to select multiple units
- **Request Type**: Service, Approval, or All
- **Status**: Filter by completion status

### Step 3: Generate Preview
- Click **"Generate Preview"** button
- Review the data in the table
- Verify filters are working correctly

### Step 4: Export
- Click **"Export as Excel"** for spreadsheet (.xlsx)
- Click **"Export as PDF"** for document (.pdf)
- File downloads automatically

---

## 📋 Report Columns

1. **Requesting Department** - Organization/Department name
2. **Title of Project/Event** - Request title
3. **Short Description** - Brief description
4. **In-Charge (Unit)** - Assigned unit
5. **Date Received** - When request was submitted
6. **Date Completed** - When marked as done
7. **Status** - Current status with color badge
8. **Remarks** - Additional notes/request type

---

## 💡 Tips

- Use **"All Time"** to see all historical data
- **Monthly** reports are great for end-of-month summaries
- **Quarterly** reports are perfect for quarterly reviews
- **Custom Range** lets you create reports for any period
- Preview before exporting to verify your filters
- Excel format is best for further data analysis
- PDF format is best for printing or archiving

---

## ⚠️ Important Notes

- Only admins can generate reports
- Reports include both Service and Approval requests
- Completion date only shows for Completed/Approved status
- Multi-select units by holding Ctrl (Windows) or Cmd (Mac)
- Large reports may take a few seconds to export

---

## 🔧 Need Help?

If you encounter any issues:
1. Try refreshing the page
2. Check your filter selections
3. Try "All Time" and "All Statuses" first
4. Contact system administrator if problems persist
